# Moscow Smartphone Store (Frontend Demo)

A multi-page demo storefront for portfolio purposes.

## Pages

- `index.html` - product catalog with filters.
- `cart.html` - shopping cart and order button.
- `contacts.html` - demo contact page.

## Demo behavior

- The website is an example only.
- No real address or phone is used.
- When user clicks `Заказать`, the message is: `уже под вашей подушкой`.

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- `localStorage` for cart state between pages

## Run

Open `index.html` in a browser and navigate with the menu links.
